# Personal Introduction Program

## 📌 Project Overview

This project is a beginner-level Python program created as part of Week 1: Python Basics.

The program asks the user for:
- Name
- Age
- Hobby

After collecting the information, it displays a friendly welcome message using Python variables and print statements.

---

## 🎯 Objectives

- Learn how to use `input()` in Python
- Store user data using variables
- Display output using `print()`
- Understand basic Python program structure

---

## 🛠️ Setup and Installation

### Step 1: Install Python
Download and install Python from:

https://www.python.org/downloads/

### Step 2: Clone the Repository

```bash
git clone <your-github-repo-link>
```

### Step 3: Open Project Folder

```bash
cd Python-Basics-Personal-Intro
```

### Step 4: Run the Program

```bash
python personal_intro.py
```
